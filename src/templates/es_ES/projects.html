Desarrollos personales

hypothesis-api-client
Una pequeña librería para simplificar el uso de la API de Hypothes.is en javascript, que es un gran servicio de anotaciones web!
zeroclaw_config
Generador web puro (HTML/CSS/JS sin dependencias) para el config.toml de ZeroClaw. Construye el formulario desde los JSON Schema oficiales (versiones 0.6.9 → 0.8.4), con previsualización en vivo, guardado de borradores, importación de TOML con informe de compatibilidad, interfaz multiidioma y búsqueda. 100% en el navegador, tus claves no salen de tu equipo.
crypto-tax
Parseador en node de movimientos y ledgers de cryptomonedas y exchanges para facilitar el cálculo de impuestos en múltiples plataformas.
dca-kraken
Script Node.js para DCA automático en Kraken con dos modos: SIMPLE (compra en cada ejecución) y SMART (compra cuando el precio cae X% o al cierre del periodo). Soporta múltiples estrategias de precio (actual, mínimo, VWAP, media), umbrales múltiples por periodo (ej. 1:25,3:25,5:25,10:25), comparación con Binance y notificaciones Telegram. Listo para cron con simulador y estado persistente.
EPlayer
Un reproductor de música multiplataforma desarrollado utilizando Electron. Escrito en javascript, html y css, extensible y liviano. ¡Actualmente en desarrollo! Conocido previamente como GCPlayer.
DBusBot
Un chatbot para ver los tiempos de llegada de los autobuses de DBus. Escrito usando Microsoft Bot Framework. Actualmente no está en funcionamiento, debido a cambios en las políticas de uso de Microsoft Bot Framework... Mi idea es reescribirlo utilizando Telegraf.
